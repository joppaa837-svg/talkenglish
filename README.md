# TalkEnglish Final v1

نسخة ويب نهائية قابلة للنشر على GitHub Pages، مصممة للموبايل وبواجهة عربية RTL.

## الموجود
- مستويات A1 إلى C1
- اختبار تحديد مستوى
- 10 دروس بمواقف حقيقية
- ترجمة عربية + نطق بالعربي لكل جملة
- نطق صوتي للجمل عبر Web Speech API
- تدريب تحدث بالميكروفون عند دعم المتصفح
- مراجعة ذكية
- لعبة ترتيب الجمل
- XP وسلسلة وتقدم وإنجازات
- حفظ التقدم محليًا على الجهاز
- PWA وService Worker للتثبيت والكاش الأساسي

## مهم
التعرف على الكلام في Web Speech API ليس مدعومًا بنفس الدرجة في كل المتصفحات، وبعض المتصفحات تستخدم خدمة تعرف خارجية. لذلك التطبيق لا يدّعي أنه يقيس جودة النطق الصوتية باحتراف.
